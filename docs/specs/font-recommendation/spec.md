# 폰트 추천

## User-visible outcomes

- 레퍼런스 영상의 번역 페이지(`/videos/[id]`) 아래쪽에 "폰트 추천" 영역이 보인다.
- 편집자가 레퍼런스 프레임 스크린샷을 올리고, 그 이미지 위에서 드래그로 텍스트 한 덩어리를 감싸고, 그 글자를 입력한 뒤 "추천"을 실행하면, 시각적으로 비슷해 보이는 무료 폰트 후보가 비슷한 순으로 정렬되어 나온다.
- 각 후보는 폰트 이름, 편집자가 입력한(또는 샘플) 글자를 그 폰트로 렌더링한 미리보기, 다운로드 링크를 함께 보여준다.
- 다운로드 링크를 누르면 그 폰트를 무료로 받을 수 있는 외부 페이지가 새 탭으로 열린다.

## Approved scope

- 번역 페이지의 한 영역으로 들어가는 폰트 추천 기능.
- 스크린샷 이미지 업로드(PNG/JPG).
- 업로드한 이미지 위에서 드래그로 사각형 영역 1개 지정. 다시 드래그하면 이전 영역 대체.
- 선택 영역의 글자를 편집자가 텍스트로 입력. 비우면 고정 샘플 문구 사용.
- "추천" 실행 시 선택 영역과 시각적으로 비슷한 순으로 정렬된 무료 폰트 후보 목록(기본 약 5개).
- 각 후보에 폰트 이름, 입력한(또는 샘플) 글자를 그 폰트로 렌더링한 미리보기, 무료 다운로드 링크 표시.
- 재사용 대상: `matchfont.git`의 `components/font-match/*`(업로드·크롭·특징 추출·유사도 정렬·후보 카탈로그·결과 표시)를 이 앱의 번역 페이지 영역으로 가져온다.

## Observable acceptance criteria

- 번역 페이지를 열면 자막 영역 아래에 폰트 추천 영역이 자기 제목과 함께 보인다.
- PNG 또는 JPG 파일을 올리면 이미지가 그 영역에 표시된다.
- 표시된 이미지 위에서 마우스 드래그로 사각형 영역을 그릴 수 있고, 다시 드래그하면 이전 영역이 대체된다.
- 글자 입력란에 값을 넣을 수 있고, 비우면 고정 샘플 문구가 대신 쓰인다.
- 영역을 지정하지 않으면 "추천"을 실행할 수 없다.
- "추천"을 실행하면 무료 폰트 후보가 여러 개(기본 약 5개), 선택 영역과 비슷한 순으로 정렬되어 나온다.
- 각 후보 항목에 폰트 이름, 입력한(또는 샘플) 글자를 그 폰트로 렌더링한 미리보기, 다운로드 링크가 모두 보인다.
- 다운로드 링크를 누르면 그 무료 폰트를 받을 수 있는 외부 페이지가 새 탭으로 열린다.
- 페이지를 새로고침하면 업로드, 선택 영역, 추천 결과가 모두 초기 상태로 돌아간다.

## Settled constraints and rationale

- **폰트 추천용 이미지는 편집자가 직접 올린 스크린샷을 쓴다.** 사용자가 A안으로 확정. 유튜브 임베드는 CORS/DRM으로 프레임을 canvas에 담을 수 없고, 썸네일은 편집자가 원하는 그 텍스트 프레임이 아닐 때가 많다. `matchfont.git`을 그대로 붙이려면 업로드 흐름이 맞다.
- **첫 버전 후보 풀은 라틴(영문) 폰트로 한정한다.** 사용자가 확정. `matchfont.git`의 카탈로그가 Google Fonts 라틴 폰트 12개이고 유사도 판별도 라틴 글자 기준이다. `matchfont` 자체 스펙도 한글을 이후 확장으로 미뤄뒀다. 한글 후보 풀과 한글 유사도 보정을 새로 만드는 것은 검증·리뷰 예산을 넘는다.
- **폰트 추천 영역은 상태를 저장하지 않는다.** `matchfont.git`이 로그인·기록 없이 한 번 쓰고 나가는 도구다. 이 영역은 레퍼런스 레코드에 아무것도 쓰지 않는다.
- **무료 폰트 출처는 Google Fonts로 한정하고, 다운로드 링크는 각 폰트의 Google Fonts 페이지로 연결한다.** `matchfont.git`이 이렇게 되어 있고, 무료·미리보기·다운로드가 쉽다.
- **추천 대상은 무료 폰트만.** `PRODUCT.md` 경계.

## Assumptions

- 폰트 추천 영역은 번역 페이지의 자막 영역 아래에 렌더링한다. `matchfont.git`의 최상위 `<h1>`은 이 앱에서 하위 영역 제목 수준으로 낮춘다.
- 후보 개수는 약 5개.
- 입력 이미지 형식은 PNG/JPG.
- 유사도 랭킹은 `matchfont.git`의 휴리스틱(크롭 픽셀에서 굵기·대비·폭 3가지 특징을 뽑아 후보와 가중 거리 비교)을 그대로 쓴다.
- 미리보기 폰트는 `next/font/google`로 빌드 시점에 불러온다. 실행 시 별도 키나 계정이 필요 없다.
- 이 영역은 번역 페이지 위에 놓이므로, 자막 레코드가 있어 번역 페이지가 존재하는 영상에서만 나타난다.

## Off-limits and why

- 영상에서 프레임 자동 추출·썸네일 자동 크롭 — 사용자가 A안(수동 업로드)으로 확정. 범위 밖.
- 한글 무료 폰트 후보 풀과 한글 유사도 보정 — 사용자가 라틴 한정으로 확정. 이후 확장.
- 스크린샷 하나에서 여러 텍스트를 자동 분리해 각각 추천 — `matchfont.git` 스펙에서도 정확도 문제로 미룬 항목.
- OCR로 글자 자동 인식 — `matchfont.git` 스펙에서 실패율 문제로 편집자 입력으로 대체.
- OS별 설치 안내, 편집 프로그램 연동 — `matchfont.git`·`PRODUCT.md` 경계.
- 선택한 폰트를 레퍼런스 레코드에 자산으로 기록하고 목록 아이콘으로 표시 — 레퍼런스 영상 DB 기능에서 아이콘 정책과 함께 정한다.
- 자막이 없어 번역 페이지가 없는 영상에서 폰트 추천만 따로 여는 경로 — 레퍼런스 영상 DB 기능에서 레코드 생성 정책과 함께 정한다.

## Deferred points

- 폰트 추천 영역을 썼는지를 레퍼런스 목록에서 "폰트 확인함" 같은 아이콘으로 보여줄지 — 레퍼런스 영상 DB 기능에서 다룬다.
- 한글 폰트 확장.
- 유사도 판별 기법 고도화 — `PRODUCT.md`가 기법 선택을 미뤄둔 상태다.

## Remaining risks

- 유사도 랭킹이 사람이 눈대중으로 매긴 특징값과 단순 휴리스틱이라, "정말 비슷하다"는 성공 신호를 늘 충족하지는 못할 수 있다. 런타임 검증은 흐름 완주(업로드 → 영역 지정 → 글자 입력 → 추천 → 정렬된 후보 목록 → 미리보기·다운로드 링크 동작)로 한정한다.
- 라틴 한정 후보 풀은 한글을 주로 쓰는 정보성 유튜버에게 쓸모가 제한될 수 있다. 한글 확장은 미룬 항목으로 남긴다.
- 크롭·canvas·`getImageData`는 브라우저에서 동작한다. 로컬 개인 사용 전제라 위험은 낮지만, canvas 접근이 막힌 환경에서는 추천이 동작하지 않는다.
- `matchfont.git`의 유사도 보정과 후보 특징값이 라틴 샘플 길이 기준이라, 아주 짧거나 아주 긴 입력에서는 폭 특징이 흔들릴 수 있다(`matchfont.git`의 follow-up에 기록됨).
