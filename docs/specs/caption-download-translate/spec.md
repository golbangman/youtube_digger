# 자막 다운로드 및 번역

## User-visible outcomes

- 레퍼런스 영상 URL을 입력하면, 영어 자막이 있는 영상의 경우 영상 재생 화면과 함께 왼쪽에 영어 원문 전체 텍스트, 오른쪽에 한국어 번역 전체 텍스트가 나란히 보인다.
- 같은 화면에서 "자막 내려받기" 버튼으로 영어 원문과 한국어 번역을 함께 담은 `.txt` 파일을 저장할 수 있다.
- 영어 자막이 없는 URL을 입력하면 "이 영상에는 영어 자막이 없어 처리할 수 없다"는 안내가 보이고, 번역 결과와 내려받기 버튼은 나타나지 않는다.
- 번역 기능은 별도 계정 등록이나 API 키, 결제 없이 동작한다.
- 처리를 마친 영상은 URL·제목·영어 자막·한국어 번역이 하나의 레코드로 로컬에 저장된다. 같은 URL을 다시 입력하면 재번역 없이 저장된 결과를 바로 보여준다.

## Approved scope

- URL 입력란과 처리 실행.
- 영어 자막 추출(`yt-dlp` 서브프로세스 호출) → 영어→한국어 번역(무료 제공자, 계정 불필요).
- 번역 페이지: 유튜브 임베드 플레이어 + 좌(영어 원문)/우(한국어 번역) 전체 텍스트.
- 영어 원문과 한국어 번역을 한 파일에 담은 `.txt` 내려받기.
- 처리 결과를 URL·제목·영어 자막·한국어 번역 단위 레코드로 로컬 저장하고, 이미 있는 URL 재입력 시 저장본 재사용.
- 재사용 대상: `youtube_caption.git`의 자막 추출(`lib/youtube.ts`), 번역(`lib/translate.ts`), 저장(`lib/store.ts`), 번역 페이지 레이아웃(`app/videos/[id]/page.tsx`) 흐름을 이 앱에 맞게 가져온다.

## Observable acceptance criteria

- 영어 자막(수동 또는 자동 생성)이 있는 유튜브 URL 입력 시: 영상 재생 화면, 좌측 영어 원문 전체 텍스트, 우측 한국어 번역 전체 텍스트가 한 화면에 모두 보인다.
- 그 화면의 "자막 내려받기"를 누르면 영어 원문과 한국어 번역이 함께 들어간 `.txt` 파일이 저장된다. 파일에는 영상 제목과 원본 URL도 포함된다.
- 영어 자막이 없는 URL 입력 시: 처리 불가 안내만 보이고, 번역 결과·내려받기 버튼은 나타나지 않는다.
- 유튜브 URL 형식이 아닌 값 입력 시: 형식이 잘못됐다는 안내가 보인다.
- 이미 처리한 적 있는 URL을 다시 입력하면, 번역 제공자 호출 없이 저장된 영어·한국어 텍스트가 곧바로 보인다.
- 처리 전 과정에서 API 키 입력이나 결제 수단 등록을 요구하지 않는다.

## Settled constraints and rationale

- **자막 대상은 영어 자막이 있는 영상으로 한정한다.** `youtube_caption.git` 재사용 코드가 영어 트랙(`en` 또는 `en-*`)만 처리한다. 이 기능의 목적은 해외 레퍼런스 영상의 내용 파악이므로 영어 원문을 전제한다.
- **번역 방향은 영어→한국어로 고정한다.** 재사용 코드가 이 방향만 지원한다. `PRODUCT.md`의 위임(번역 방향은 `youtube_caption.git` 구현을 따름)과 일치한다.
- **번역은 계정·비용 없는 무료 제공자로 한정한다.** 재사용 코드가 Google 비공식 엔드포인트 → MyMemory 순의 폴백 체인을 쓴다. 개인용 1인 로컬 도구이고 번역 품질은 "내용 파악 수준이면 충분"이므로 유료 API 설정 부담을 질 이유가 적다.
- **자막 추출은 `yt-dlp`를 서버 서브프로세스로 호출한다. 이 앱을 실행하는 컴퓨터에 `yt-dlp`가 설치되어 있어야 한다.** 유튜브가 자막 요청에 봇 방지 토큰을 요구해, `yt-dlp` 없이는 자막을 안정적으로 가져올 수 없음이 `youtube_caption.git`에서 이미 확인됐다. `yt-dlp` 설치는 무료·계정 불필요이지만 새로운 실행 전제가 된다.
- **내려받는 자막 파일은 타임코드 없는 `.txt`로 한다.** 사용자가 A안으로 확정. 재사용 코드가 자막을 받을 때 세그먼트 타임코드를 버리고 전체를 한 텍스트로 이어붙이므로, `.srt` 같은 타임코드 자막은 이 코드를 그대로 쓰는 한 만들 수 없다.

## Assumptions

- 자동 생성 자막을 포함해 영어 자막 트랙이 하나라도 있으면 처리 대상으로 본다. 수동 자막과 자동 생성 자막이 모두 있으면 수동 자막을 우선 사용한다. (감수하는 위험: 자동 생성 자막 품질이 낮으면 번역 결과도 함께 떨어진다. 실사용 후 문제되면 조정.)
- 영상 재생은 유튜브 자체 임베드 플레이어를 사용한다.
- 처리 결과 레코드는 서버 측 로컬 저장소에 보관해 브라우저·기기와 무관하게 재열람할 수 있게 한다.
- 이미 저장된 URL을 다시 입력하면 재번역 없이 기존 레코드를 재사용한다.
- 내려받는 `.txt` 파일 이름은 영상 제목 기반으로 한다.
- 이 기능의 화면은 URL 입력과 번역 페이지까지다. 저장된 레퍼런스 영상을 목록으로 훑어보고 다시 여는 화면은 별도 기능(레퍼런스 영상 DB)에서 다룬다. 이 기능은 그 목록이 나중에 표시할 수 있도록 레코드를 남기는 데까지만 책임진다.

## Off-limits and why

- 타임코드 있는 `.srt`/`.vtt` 자막 파일 출력 — 사용자가 A안(`.txt`)으로 확정. 재사용 코드가 타임코드를 버리므로 별도 파싱 구현이 필요해 범위 밖.
- 영어가 아닌 원어 자막 처리, 다국어 번역 — 재사용 코드가 영어→한국어만 지원. 범위 밖.
- 재생 시점에 맞춘 자막 하이라이트·자동 스크롤 — 전체 텍스트 나열로 충분. 범위 밖.
- 레퍼런스 영상 목록 화면(썸네일·자산 아이콘·메모·삭제) — `PRODUCT.md`의 별도 기능. 범위 밖.
- 폰트 추천·BGM 추출·영상 다운로드 영역 — 각각 별도 기능. 범위 밖.
- 유료 번역 API 연동, 로그인·다중 사용자 — 개인용 1인 무료 도구. 범위 밖.

## Deferred points

- 영어 자막이 없는 영상(예: 한국어 레퍼런스 영상)을 그래도 레퍼런스 목록에 등록해 BGM·클립 등 다른 자산만 확보하도록 할지는 이 기능에서 정하지 않는다. 지금은 "자막 처리 불가" 안내만 하고 자막 레코드를 만들지 않는다. 레퍼런스 영상 DB 기능에서 등록 정책을 함께 정한다.
- 저장된 레코드의 정렬·검색 방식 — 레퍼런스 영상 DB 기능에서 다룬다.

## Remaining risks

- 무료 번역 제공자는 요청 빈도·일일 할당량 제한이 있어 긴 자막 번역이 느리거나 실패할 수 있다. 재사용 코드가 Google 비공식 → MyMemory 폴백을 적용하지만, 짧은 시간에 같은 IP로 대량 호출하면 두 제공자가 동시에 막힐 수 있음이 `youtube_caption.git`에서 확인됐다(`docs/follow-ups/translate-provider-rate-limit.md`). 청크 재시도 간격이나 세 번째 제공자 추가가 다음 완화책.
- `yt-dlp`가 설치되지 않은 환경에서는 자막 추출이 동작하지 않는다. 설치 여부를 사전 확인하고 안내하는 처리가 필요할 수 있다.
- `yt-dlp`의 유튜브 우회 방식은 유튜브 쪽 변경으로 다시 깨질 수 있다(외부 도구 유지보수 의존).
- `.txt` 다운로드는 브라우저 환경에서 파일 저장을 트리거하는 방식에 의존한다. 로컬 개인 사용 전제라 문제는 낮지만, 저장 트리거가 막히는 브라우저 설정에서는 동작하지 않는다.
