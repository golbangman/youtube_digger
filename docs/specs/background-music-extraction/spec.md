# 배경음악 추출

## User-visible outcomes

- 레퍼런스 영상의 번역 페이지(`/videos/[id]`)에서 폰트 추천 영역 다음에 "배경음악" 영역이 보인다.
- "MP3 추출" 같은 실행을 누르면, 오디오를 내려받는 동안 실제 진행률 퍼센트가 바에 차오르고, 그다음 "MP3로 변환 중" 상태가 보인다.
- 추출이 끝나면 그 영역에 MP3 다운로드 링크가 나타나고, 눌러서 파일을 저장할 수 있다.
- 같은 영상을 나중에 다시 열면, 재추출 없이 이미 만들어진 MP3를 바로 받을 수 있다.

## Approved scope

- 번역 페이지의 한 영역으로 들어가는 배경음악 추출 기능.
- 영상 오디오 전체를 하나의 MP3 파일로 추출. 구간 자르기나 음악·말소리 분리는 없다.
- 추출 진행 상황 표시: 내려받기 단계는 실제 퍼센트, 변환 단계는 진행 중 상태.
- 추출한 MP3를 그 영상과 연결해 로컬에 보관.
- 완료 후, 그리고 재방문 시 MP3 다운로드 링크 제공.

## Observable acceptance criteria

- 번역 페이지를 열면 폰트 추천 영역 아래에 배경음악 영역이 자기 제목과 함께 보인다.
- 추출을 실행하면 진행률 바가 나타나고, 내려받기 동안 퍼센트가 0에서 100 쪽으로 증가하는 것이 눈에 보인다.
- 내려받기가 끝나면 변환 중임을 알리는 상태가 보인다.
- 추출이 끝나면 MP3 다운로드 링크가 그 영역에 보이고, 누르면 오디오 파일이 저장된다. 파일 이름은 영상 제목을 기반으로 한다.
- 추출에 실패하면(영상 오디오 없음, yt-dlp/ffmpeg 오류 등) 실패 안내가 보이고, 절반만 만들어진 파일이나 다운로드 링크는 남지 않는다.
- 이미 MP3가 만들어진 영상을 다시 열면, 추출을 다시 실행하지 않고 곧바로 다운로드 링크가 보인다.
- 추출이 진행되는 동안에도 같은 페이지의 자막·폰트 추천 영역은 그대로 쓸 수 있다.

## Settled constraints and rationale

- **오디오는 통째로 MP3 하나로 뽑는다. 말소리와 음악을 분리하지 않는다.** `PRODUCT.md` 경계이자 사용자가 define-product에서 확정.
- **진행률은 내려받기 실제 퍼센트 + 변환 단계 표시로 한다.** 사용자가 A안으로 확정. yt-dlp의 진행 출력을 파싱해 서버에서 클라이언트로 흘려보낸다. ffmpeg 변환 단계는 퍼센트를 잡기 어려워 진행 중 상태로만 보여준다.
- **추출한 MP3는 로컬에 보관한다.** 사용자가 A안으로 확정. 자막 캐싱 방식과 일관되며, 재방문마다 재추출하는 낭비를 피한다. 로컬 단일 사용자 도구라 디스크 부담은 감수한다.
- **추출은 `yt-dlp`와 `ffmpeg`를 서버에서 호출한다. 이 앱을 실행하는 컴퓨터에 둘 다 설치되어 있어야 한다.** `yt-dlp`는 자막 기능에서 이미 쓰고 있고, MP3 변환에는 `ffmpeg`가 추가로 필요하다. 둘 다 무료·계정 불필요이지만 `ffmpeg`가 새 실행 전제로 붙는다.

## Assumptions

- 배경음악 영역은 번역 페이지에서 폰트 추천 영역과 영상 다운로드 영역 사이에 놓인다.
- MP3 음질은 `yt-dlp`가 고르는 최적 오디오 소스를 기준으로 한 기본값을 쓴다. 별도 비트레이트 선택 UI는 없다.
- 진행 상황을 클라이언트에 전달하는 방식(폴링·스트리밍 등)은 구현이 정한다. 관찰 기준은 "퍼센트가 눈에 보이게 갱신되고, 끝나면 링크가 뜬다"이다.
- 추출한 MP3는 영상 단위로 하나만 보관한다. 다시 추출하면 이전 파일을 대체한다.
- 이 영역은 번역 페이지 위에 놓이므로, 자막 레코드가 있어 번역 페이지가 존재하는 영상에서만 나타난다.
- 다운로드는 브라우저가 파일 저장을 시작하는 방식(첨부 헤더를 붙인 링크)으로 제공한다.

## Off-limits and why

- 음악만 분리 추출(보컬·말소리 제거) — `PRODUCT.md` 경계. 통째로 MP3만.
- 특정 구간만 잘라 추출 — 사용자가 "통째로"로 확정. 범위 밖.
- 비트레이트·포맷 선택(WAV, FLAC 등) — MP3 하나로 확정. 범위 밖.
- 변환 단계의 정확한 퍼센트 — ffmpeg 진행률 파싱은 불안정. 진행 중 상태로 대체.
- 배경음악을 확보했음을 레퍼런스 목록에서 아이콘으로 표시 — 레퍼런스 영상 DB 기능에서 아이콘 정책과 함께 정한다.
- 자막이 없어 번역 페이지가 없는 영상에서 배경음악 추출만 따로 여는 경로 — 레퍼런스 영상 DB 기능의 레코드 생성 정책과 함께 정한다.
- 여러 영상을 동시에 추출할 때의 큐·동시성 제어 — 로컬 단일 사용자 전제. 범위 밖.

## Deferred points

- 배경음악 추출 여부를 레퍼런스 목록에서 아이콘으로 보여줄지 — 레퍼런스 영상 DB 기능에서 다룬다.
- 보관한 MP3의 정리(오래된 파일 삭제 등) 방식 — 디스크가 실제로 문제될 때 다룬다.

## Remaining risks

- `yt-dlp` 또는 `ffmpeg`가 설치되지 않은 환경에서는 추출이 동작하지 않는다. 설치 여부를 사전 확인하고 안내하는 처리가 필요할 수 있다.
- 긴 영상은 내려받기·변환에 수십 초 이상 걸릴 수 있다. 그동안 서버 프로세스가 점유되고, 브라우저를 닫으면 진행 상태를 다시 붙이기 어렵다.
- `yt-dlp`의 유튜브 접근 방식은 유튜브 쪽 변경으로 깨질 수 있다(외부 도구 유지보수 의존). 자막 기능과 같은 위험이다.
- 보관한 MP3가 쌓이면 디스크를 계속 쓴다. 정리 방식은 미룬 항목.
- 추출 도중 실패했을 때 남은 임시 파일을 확실히 지우지 못하면 반쪽 파일이 남을 수 있다. 수용 기준에 "반쪽 파일·링크가 남지 않는다"를 넣어 검증한다.
